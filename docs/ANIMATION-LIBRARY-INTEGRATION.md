# GSAP, Lenis and selected React Bits integration

Approved 2026-10-10 after the component research/selection. Baseline release: 4d5fc5925b9d202f7d479394560b582d8c958f7d.

- Pin gsap3.15.0, @gsap/react2.1.2 and lenis1.3.26. Use GSAP/useGSAP for scoped arrival and visual Henshin; mechanical run-token deadlines remain authoritative. Replace corresponding CSS animations/React RAF rendering to avoid competing property owners. Restore visual endpoints on state change and sync from wall-clock time after page visibility changes.
- Adapt GlareHover, SplitText and AnimatedContent from official React Bits revision d86fccbd477786f94ca7eb891fbe0ec039d3cd3b, TypeScript/CSS variants. Retain the supplied MIT+Commons Clause license and component provenance. Their use is within this portfolio application.
- GlareHover sits inside each real deck button around its art: white0.15 glare, 400ms, transparent border/background, decorative overlay ignores input. Disable on reduced motion, dragging and occupied cards. Keep button geometry and pointer-capture lease unchanged.
- SplitText reveals only the active project title, after Henshin. Preserve existing h1/focus ref; the inner span is split by GSAP, with safe revert/cleanup. Trigger on mounted project state, with font-ready handling, rather than a window scroll trigger. Plain text remains available as fallback.
- AnimatedContent reveals project facts and abilities once per mount, with ScrollTrigger explicitly bound to the project panel. Facts can shift12px; interactive ability regions use opacity only so their hit areas do not move. Keyboard focus/input finishes a reveal immediately. Default HTML stays visible when animation infrastructure is unavailable.
- Lenis owns only .project-stage, with its inner content as content element and GSAP ticker as the single animation loop. Native touch and reduced-motion scroll remain direct. Programmatic ability-panel scrolling uses this same instance; overflow content changes resize it. Destroy the instance and remove ticker/listener bindings on project teardown.

New checks cover renderer-stall independence, scoped scroll/resource cleanup and animation interruption.
